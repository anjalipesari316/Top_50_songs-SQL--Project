🎵 Top 50 Songs SQL Analysis

📌 Project Overview
This project analyzes a Top 50 Songs dataset using MySQL and SQL.
The objective is to explore song and artist data and extract useful insights using SQL queries.

🛠️ Tools Used
- MySQL
- SQL
- GitHub

📂 Project Files
- Top_songs.csv — Dataset used for the analysis
- SQL_Queries.sql — SQL queries used for data analysis
- screenshots/ — Screenshots of SQL queries and their outputs

🔍 SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- LIMIT
- COUNT()
- SUM()
- AVG()
- MAX()
- MIN()
- Aggregate Functions
- Subqueries

📊 Analysis Performed
The project explores:
- Top songs based on popularity
- Artist-wise song counts
- Most popular artists
- Average song popularity
- Highest and lowest values
- Song rankings
- Different patterns in the dataset

🎯 Project Goal
The goal of this project is to demonstrate practical SQL skills including data filtering, sorting, grouping, aggregation, and analysis.
